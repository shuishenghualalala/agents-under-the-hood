# agents-under-the-hood

A repository of source-code dissection notes for various **AI Agent** open-source projects.

学习与拆解各种 **AI Agent** 开源项目的源码笔记仓库。

Each subdirectory corresponds to a dissected Agent project — diving into the source to understand how it works, its architecture, and implementation details.

每个子目录对应一个被拆解研究的 Agent 项目，通过深入源码理解其工作原理、架构设计与实现细节。

---

## Directory Structure / 目录结构

```
agents-under-the-hood/
├── how-codex-works/            # Codex —— Agent core / Agent 核心原理拆解
├── how-codex-security-works/   # Codex security / Codex 安全机制拆解
├── how-deepseek-harness-works/ # DeepSeek Harness —— Agent dissection / Agent 拆解
└── how-kimi-code-works/        # Kimi Code —— Agent implementation / Agent 实现拆解
```
