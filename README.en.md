# agents-under-the-hood

A repository of source-code dissection notes for various **AI Agent** open-source projects.

Each subdirectory corresponds to a dissected Agent project — diving into the source to understand how it works, its architecture, and implementation details.

---

## Directory Structure

```
agents-under-the-hood/
├── how-codex-works/            # Codex —— Agent core
├── how-codex-security-works/   # Codex security
├── how-deepseek-harness-works/ # DeepSeek Harness —— Agent dissection
└── how-kimi-code-works/        # Kimi Code —— Agent implementation
```

Continuously add more Agent project dissections, such as Hermes, OCC (Open Claude Code), OpenClaw, and more.
